# Sistema de Gestión de Laboratorio

Este es un sistema de gestión de laboratorio desarrollado en C# con Windows Forms.

## Cómo eliminar este repositorio de tu cuenta de GitHub

Si deseas eliminar completamente el repositorio **SistemaGestionLab3** de tu lista de repositorios en GitHub, sigue estos pasos:

### Opción 1: Eliminar el repositorio permanentemente

⚠️ **ADVERTENCIA:** Esta acción es permanente y no se puede deshacer. Se perderán todos los datos, código, issues, pull requests y configuraciones.

1. Ve a la página principal del repositorio en GitHub: `https://github.com/danicardon/SistemaGestionLab3`
2. Haz clic en **Settings** (Configuración) en la barra de navegación del repositorio
3. Desplázate hacia abajo hasta la sección **Danger Zone** (Zona de peligro)
4. Haz clic en **Delete this repository** (Eliminar este repositorio)
5. Lee las advertencias cuidadosamente
6. Escribe el nombre completo del repositorio (`danicardon/SistemaGestionLab3`) para confirmar
7. Haz clic en **I understand the consequences, delete this repository** (Entiendo las consecuencias, eliminar este repositorio)

### Opción 2: Archivar el repositorio (recomendado)

Si no estás seguro de querer eliminar permanentemente el repositorio, puedes archivarlo. Esto lo hace de solo lectura y lo marca como archivado:

1. Ve a la página principal del repositorio en GitHub: `https://github.com/danicardon/SistemaGestionLab3`
2. Haz clic en **Settings** (Configuración)
3. Desplázate hacia abajo hasta la sección **Danger Zone** (Zona de peligro)
4. Haz clic en **Archive this repository** (Archivar este repositorio)
5. Confirma la acción

El repositorio archivado seguirá visible pero marcado como archivado, y no permitirá nuevos commits, issues o pull requests.

### Opción 3: Hacer el repositorio privado

Si solo quieres que el repositorio no sea visible públicamente:

1. Ve a **Settings** (Configuración)
2. En la sección **Danger Zone**, busca **Change repository visibility** (Cambiar visibilidad del repositorio)
3. Haz clic en **Change visibility**
4. Selecciona **Make private** (Hacer privado)
5. Confirma la acción

## Sobre el proyecto

Este sistema incluye:
- Gestión de empleados
- Módulo de Recursos Humanos (RRHH)
- Sistema de login y registro de usuarios
- Conexión a base de datos MySQL

## Requisitos

- .NET Framework 4.7.2
- MySQL Database
- Visual Studio 2015 o superior
